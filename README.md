Play With Arrays
📄 Description
This project contains small JavaScript exercises focused on mastering arrays. It was created as part of my journey to becoming a frontend developer and improving my problem-solving skills.
The goal of this project is to understand how arrays work and how to manipulate them using core JavaScript methods.
  
🚀 What I Practiced
This project includes functions that practice:
Creating and accessing arrays
Looping through arrays
Searching inside arrays

 🎯 Purpose
The purpose of this project is to build a strong foundation in JavaScript logic and prepare for real-world frontend development.
 
💡 What I Learned
Working on this project helped me:
Understand how to think like a programmer
Break problems into steps
Become more comfortable writing JavaScript functions
